## 🚀 What It Is
OctaneRender for Windows is OTOY's GPU render engine, delivered as a plugin that hooks into host 3D applications like Cinema 4D and Blender. It reads your existing scene and uses the graphics card to calculate realistic light and materials, letting you preview near-final frames while you keep modeling and lighting. It works as a plugin, and is also available as a standalone application for opening and rendering supported scene files on their own.

## ✨ Key Features
> OTOY OctaneRender turns your GPU into an interactive, physically based rendering workhorse.

- 🎬 **Interactive GPU viewport** — See lighting and material updates render live as you work.
- 💡 **Spectral, physically based engine** — Produce believable light, shadows, and reflections by default.
- 🧩 **Plugin for popular 3D hosts** — Slots into applications such as Cinema 4D and Blender.
- 🎛️ **Rich node-based materials** — Layer textures and shaders through the OctaneRender interface.
- 📦 **Standalone edition** — Render supported scene files without a host when you need to.

## 💻 Requirements
| Component | Minimum | Recommended |
|-----------|---------|-------------|
| OS | Windows 10 64-bit | Windows 11 64-bit |
| Host application | A supported version of a 3D host such as Cinema 4D or Blender | The latest supported release of your chosen 3D host |
| Graphics | A CUDA-capable NVIDIA GPU meeting the engine's minimum | A high-VRAM NVIDIA GPU for heavier scenes |
| Processor | A modern 64-bit multi-core processor | A recent multi-core desktop processor |
| Memory | 8 GB RAM | 16 GB RAM or more |
| Storage | A few GB free for the plugin and cache | An SSD with generous free space |

## 📥 Setup
1. Click the **Download** button above to grab the latest OctaneRender package for your host application.
2. Run the installer, or add OctaneRender via your host's plugin or add-on manager, and complete the setup steps.
3. Launch your 3D host application, where OctaneRender appears in the render and material menus; activate your OTOY license or sign in to OTOY when asked.

## 🎯 First Steps
1. Open your project inside the host 3D application.
2. Choose OctaneRender as the render engine in the render settings.
3. Enable the live render viewport to begin GPU rendering.
4. Apply OctaneRender materials and refine your lights.
5. Export the finished frame or sequence when you are happy.

## ❓ Questions
**Is there an OctaneRender free download?**
OTOY offers OctaneRender by subscription and provides a free or limited tier, so a free download to try the engine is available; a free full copy of the paid tiers is not.

**Which versions of Windows are supported?**
OctaneRender supports 64-bit Windows, and it runs best on Windows 10 or Windows 11.

**Is my data secure?**
Your scene files and renders remain on your Windows PC unless you opt into a cloud workflow, keeping your work under your control.
